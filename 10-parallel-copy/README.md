# Параллельное копирование больших блоков данных при помощи пула потоков

- Завести пул из заданного числа потоков

- Реализовать функцию void* parallel_memcpy(void* dst, const void* src, size_t size)

- При копировании потоки пула помогают потоку приложения

- Для простоты: 
    - приложение однопоточное
    - dst и src не перекрываются

- Протестировать корректность
    - Совпадение исходных и скопированных данных

- Измерить и сравнить производительность
    - Размер копируемых данных 256М
    - В пуле 0...8 потоков
